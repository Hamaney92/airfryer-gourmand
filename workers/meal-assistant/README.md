# Assistant Airfryer Gourmand

Source reprise du pilote autorisé du 16 novembre 2026, désormais versionnée avec le site. Le pilote historique `/api/repas` et son menu restent disponibles. La page du site appelle `/api/recherche` : l'IA extrait une intention bornée, puis le navigateur retrouve exclusivement les recettes du catalogue généré au build.

Déployer avec l'accès Wrangler existant : `wrangler deploy --config workers/meal-assistant/wrangler.jsonc --var TRIAL_ENABLED:true`. Sans cet override explicite, le fichier de configuration désactive l'essai par défaut. Aucune clé utilisateur nécessaire ni secret dans le front. Aucun nouveau plan payant activé.

Le domaine principal, sa variante www et le domaine du pilote figurent dans la liste CORS. Le limiteur autorise 10 appels par minute et par localisation Cloudflare. Les sorties sont bornées à 220 jetons et validées avant utilisation. Le Worker cesse d'attendre après 9 secondes, sans nouvelle tentative automatique. Cette échéance ne garantit pas l'annulation de l'inférence par le fournisseur. La recherche locale reste disponible si l'IA échoue.

Limites : recherche lexicale + interprétation facultative, sans compréhension universelle. La disponibilité d'ingrédients n'établit ni quantité ni absence d'allergène. Les adaptations intégrées sont limitées à des herbes aromatiques ; aucun nouveau temps de cuisson généré. Le filtre écarte aussi certains produits préparés ambigus. La page de résultats est noindex et n'entre pas dans le sitemap. Le catalogue ne contient que les recettes publiées au build.

Le code utilise `@cf/mistralai/mistral-small-3.1-24b-instruct` pour remplacer Llama 3.2 3B, dont Cloudflare annonce la dépréciation le 20 novembre 2026. Chaque route envoie son schéma `guided_json` et valide la réponse. Les deux routes conservent le format public de leurs statistiques d'usage. L'estimation du pilote utilise les tarifs consultés le 18 novembre 2026, soit 31 876 neurones par million de jetons entrants et 50 488 par million de jetons sortants. Le forfait, le quota restant et la disponibilité du modèle sont à contrôler avant tout essai réel ou activation. En cas de repli, déployer avec `TRIAL_ENABLED:false` et vérifier les recettes sur le site.
